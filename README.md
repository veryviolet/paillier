# paillier

Аддитивно-гомоморфное шифрование Paillier для Guardora: привязка к
Python поверх крейта [`fast-paillier`][fp] (LFDT-Lockness, MIT OR
Apache-2.0).

Криптографию мы не пишем — она в крейте. Здесь склейка: кодирование
`float` в целое, сериализация в байты фиксированной длины и
параллельное шифрование.

## Зачем отдельный пакет

Вертикальное обучение с защитой упирается в шифрование: оно занимает
почти всё время крипто-раунда, а сложения после перехода на бакеты
перестают быть заметными.

Что есть на рынке под Python 3.13 и что из этого следует:

| | шифрование | без параллелизма | сложение | расшифровка | шифротекст | ошибка суммы |
|---|---|---|---|---|---|---|
| `heu` (C++) | 0.69 мс | 0.69 мс | 10.2 мкс | 2.79 мс | 524 Б | 2.7e-07 |
| этот пакет | 1.60 мс | 9.36 мс | 82.3 мкс | 5.32 мс | 512 Б | 2.4e-09 |
| `phe` (Python + gmpy2) | 9.37 мс | 9.37 мс | 52.2 мкс | 2.72 мс | 1233 Б | 5.7e-14 |
| `lightphe` (чистый Python) | 128.7 мс | 128.7 мс | 57.9 мкс | 104.6 мс | 1232 Б | 2.4e-09 |

Замерено на одном наборе, ключ 2048 бит, Python 3.10 (единственный, где
работает `heu`).

**Почему не `heu`.** Он быстрее всех, но под CPython 3.13 не работает:
`sf-heu==0.6.0b0` честно помечена `cp310` и не ставится;
`sf-heu==0.4.2b0` помечена `cp38-abi3`, ставится и падает при импорте на
`_PyObject_NextNotImplemented` — символе, удалённом из CPython 3.12. То
есть метка `abi3` там ложная.

**Почему не `phe`.** Втрое-впятеро медленнее и вдвое длиннее шифротекст.
Зато точность у него на пять порядков лучше — экспонентное кодирование
против фиксированного масштаба; это стоит помнить.

**Что предстоит.** Разрыв с `heu` тринадцатикратный в одном потоке при
одинаковой длинной арифметике, то есть объясняется не языком, а
отсутствующими оптимизациями. Классических для Paillier три:

- `g^m mod n²` при `g = n+1` считается как `1 + m·n` — одно умножение
  вместо возведения в степень;
- `r^n mod n²` через китайскую теорему об остатках, порознь по `p²` и
  `q²`;
- заранее заготовленный запас `r^n`.

Первые два — чистая арифметика. Третий трогает стойкость: повторное
использование `r` ломает семантическую безопасность, и вводить его можно
только с явной проверкой, что каждое значение расходуется однократно.

## Лицензии

Пакет — MIT OR Apache-2.0, как и `fast-paillier`, форк которого он
использует. `heu` под Apache 2.0: его решения и код можно брать с
сохранением уведомления.

## Сборка

```
cargo build --release
```

Готовый `target/release/libpaillier.so` кладётся в `site-packages` под
именем `paillier.so`.

[fp]: https://github.com/LFDT-Lockness/fast-paillier
