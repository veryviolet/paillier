# Первый прогон

## Ключ

```python
import paillier

pub, sec = paillier.generate_keypair(2048)
```

Порождаются **безопасные простые** — `p = 2p′ + 1`, где `p′` тоже
просто. Это дороже блюмовых (секунды против доли секунды), и это плата
за то, что неглаткость порядка `hs` выполняется **по построению**, а не
статистически. Разбор — [Схема](../concepts/scheme.md).

Меньше 2048 бит ключ не порождается вовсе: NIST SP 800-57 требует этой
длины для стойкости в 112 бит, а всё, что короче, — не криптография.

## Шифрование, сложение, расшифровка

```python
values = [1.5, 2.25, -0.75]

blobs = [bytes(b) for b in paillier.encrypt_many(pub, values)]
total = paillier.add_many(pub, blobs)

paillier.decrypt(sec, total)   # 3.0
```

`encrypt_many` шифрует **пачкой и по всем ядрам**: на этой машине 6500
элементов в секунду против 980 в одном потоке. Шифровать по одному в
цикле Python — значит выбросить этот множитель.

`add_many` тоже берёт пачку: одно обращение в Rust на всю тысячу
слагаемых вместо тысячи обращений.

## Шифрование чужим ключом

Стороне, которая только шифрует, закрытый ключ не нужен — и не нужен
никакой другой параметр, кроме модуля:

```python
wire = bytes(pub.modulus_bytes())      # это всё, что уезжает по проводу

peer = paillier.PublicKey.from_n(wire)
blobs = [bytes(b) for b in paillier.encrypt_many(peer, [7.0, 8.0])]
```

`from_n` выводит `hs` **сам**, из одного `n`. Импортировать его извне
было бы проще, но тогда шифрующему пришлось бы доверять чужому числу,
которое проверить вычислением невозможно ни при какой цене.

Сборка ключа пира стоит около 0.03 с при 3072 битах, поэтому делайте её
**один раз на сессию**, а не на каждое сообщение: вместе с ключом
строится таблица степеней, ради которой всё и затевалось.

## Масштаб

По умолчанию `10^8`. Если данные знакопостоянные и суммы длинные —
счётчики бакетов, квадраты градиентов, — возьмите больше:

```python
blobs = paillier.encrypt_many(pub, values, scale_pow10=12)
```

Масштаб едет **в самом шифротексте**, поэтому расшифровка берёт его
оттуда, а `add_many` отказывает на пачке с разными масштабами.
Договариваться сторонам не о чем. Разбор —
[Кодирование и масштаб](../concepts/encoding.md).

## Чего делать нельзя

```python
paillier.add_many(pub, blobs_from_another_key)   # молча испортит сумму
```

Проверки на «этот шифротекст сделан этим ключом» нет и быть не может:
из одного `n` она не выводится. Отказ придёт позже, у владельца, и без
адреса. Следите за тем, чтобы пачка была под одним ключом.
